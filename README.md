**Descripción del proyecto**:


Una empresa de desarrollo de software desea construir una versión académica del juego Sokoban como producto
base para futuras extensiones (editor de niveles, analizador automático de soluciones, ranking global, etc.).
El equipo de desarrollo deberá diseñar e implementar una aplicación de escritorio con interfaz gráfica 2D en JavaFX
que permita jugar niveles cargados desde archivos externos en formato Json.
El objetivo del juego es ubicar todas las cajas sobre las posiciones objetivo dentro de un almacén representado como
una cuadrícula bidimensional. El jugador solo puede desplazarse en cuatro direcciones y únicamente puede empujar
cajas si la posición siguiente está libre. No es posible jalar cajas.
El sistema debe impedir movimientos inválidos y detectar correctamente cuándo un nivel ha sido completado.
Además del funcionamiento básico, la empresa desea que el sistema permita registrar y analizar información de las
partidas realizadas.
El proyecto debe abordarse como un proceso de ingeniería de software, no solo como una implementación
directa.
